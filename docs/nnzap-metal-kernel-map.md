## Specialized compile constants

Milestone 1 shader compile tests use `SPEC_HIDDEN_K=512`, `SPEC_INTER_K=1024`, and `SPEC_GS=32` for `qmv_specialized.metal` and `q4mv_bf16_specialized.metal`; those values satisfy the reference static assertions and exercise the build-time macro path without claiming final Bonsai/Qwen model dimensions.
